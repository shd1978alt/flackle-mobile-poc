# Satoshi

Satoshi by Indian Type Foundry (ITF), used for names, message text and labels as in the Figma design.

Bundled weights (the ones the design uses): Regular, Medium, Bold, and Italic (for the "Message deleted" /
"Unsupported message" placeholders).
